# ビンゴ抽選機

ビンゴゲームの数字（1〜75）を重複なくランダムに抽選する Web アプリです。
`index.html` 1ファイルだけで動き、サーバーやビルドは不要です。

## 使い方

`index.html` をブラウザで開き、「抽選する」を押します（スペースキー / Enter でも抽選できます）。

- 抽選済みの数字は B・I・N・G・O の表に色付きで表示され、最後に出た数字は強調されます
- 「1つ戻す」で直前の抽選を取り消し、「リセット」で最初からやり直せます
- 抽選結果はブラウザに保存されるため、ページを再読み込みしても続きから再開できます
- 「演出あり」で数字が回るアニメーション、「読み上げ」で音声読み上げを切り替えられます

## 公開

静的ファイルなので、GitHub Pages や Vercel などにそのまま置くだけで公開できます。

Vercel のプロジェクト `bingo-app` と連携していて、デフォルトブランチへの push で
https://bingo-app-sepia.vercel.app/ に自動デプロイされます（ほかのブランチはプレビュー）。
